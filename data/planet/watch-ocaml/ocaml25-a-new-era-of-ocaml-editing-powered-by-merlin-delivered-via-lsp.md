<p>A New Era of OCaml Editing: Powered by Merlin, Delivered via LSP (Video, OCaml 2025)<br/>
Xavier Van de Woestyne, Sonja Heinze, Ulysse G&eacute;rard, and Muluh Godson<br/>
(Tarides; Tarides; Tarides; Tarides)</p>
<p>Abstract: In an era where the number of code editors keeps growing, supporting only Vim and Emacs is no longer enough for a modern language like OCaml. Maintaining a proliferation of dedicated editor clients has become a real burden &mdash; what we unformally call the Editor Burnout. Fortunately, Language Server Protocol (LSP), which was originally introduced in 2016 for the editor Visual Studio Code, offers a generic open standard for all editors.<br/>
In this presentation, we will present our work on adopting LSP. We will explain how it has significantly improved OCaml editor support while keeping maintenance efforts to a minimum &mdash; we&rsquo;ll also explain the costs it comes with.</p>
