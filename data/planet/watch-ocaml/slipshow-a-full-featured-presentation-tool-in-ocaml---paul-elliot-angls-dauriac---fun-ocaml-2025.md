<p>Slipshow: A Full-Featured Presentation Tool in OCaml</p>
<p>Paul-Elliot Angl&egrave;s d'Auriac</p>
<p>ABSTRACT</p>
<p>Slipshow is a tool to create interactive presentations. Started as a JavaScript project, it is now fully written in OCaml and features a runtime engine, a compiler, a collaborative editing website, a VSCode extension, a standalone app...</p>
<p>This talk tells the story of how it is possible to develop and maintain such a challenging project as a single developer.</p>
