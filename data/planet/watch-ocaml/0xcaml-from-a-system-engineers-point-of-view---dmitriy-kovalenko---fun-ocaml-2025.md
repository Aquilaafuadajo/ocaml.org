<p>0xCaml From a System Engineer's Point of View</p>
<p>Dmitriy Kovalenko (LightSource)</p>
<p>ABSTRACT</p>
<p>I do a lot of Rust, C, Zig and whatever else cursed systems programming languages are there. So recently 0xCaml popped out and I was def interested if I can finally use it. So I did some research on how it actually works comparing to native OCaml and other languages and try to build odiff (the fastest image comparison lib in the world) with 0xCaml. Here is what I learned.</p>
